# The Pale Blue Dot

고등학교 지구과학 · 통합과학 탐구 활동 모음. 브라우저만 있으면 되고, 설치할 것이 없습니다.

## 활동 목록

| 과목 | 활동 |
|---|---|
| 중학교 3학년 과학 | 구름 발생 실험 · 중위도 저기압 |
| 통합과학 1 | 원소의 기원 · 우주의 원소 공장 · 지구 시스템 · 물질의 순환 · 판구조론 |
| 통합과학 2 | 화석과 지질 시대 · 대멸종과 생물 다양성 · 복사 평형과 지구 온난화 · 사막화와 엘니뇨 |

각 활동은 5~7개의 단계로 나뉘고, 마지막에 **활동지를 A4로 인쇄하거나 PDF로 저장**할 수 있습니다.

## 만들 때 지킨 것

- **실측 자료를 쓴다.** PBDB 화석 기록, Open-Meteo 기상 자료, USGS 지진 목록 등 공개 API에서 받아옵니다.
- **인터넷이 끊겨도 열린다.** 모든 외부 자료에는 내장 대체 자료와 상태 표시가 붙어 있습니다.
- **학생이 판단한다.** 정답을 먼저 보여 주지 않고, 근거를 모아 스스로 결론에 이르게 합니다.

## 원소의 기원 — 사진에서 파장 읽기

학생이 CD 분광기로 찍은 사진을 올리면 **파장에 따른 세기 그래프**로 바꿔 줍니다.
봉우리를 눌러 파장을 재고, 방출·연속·흡수 스펙트럼을 판정하고, 어느 원소인지 기준 파장표와 대조합니다.

실제 수소 방전관 사진으로 검증한 정확도는 **RMS 1.2~1.4 nm** 입니다.

- 사진은 **기기 안에서만** 처리되며 어디에도 전송되지 않습니다.
- 촬영 시 **확대(줌) 1.0배 고정**, 가운데 직진광과 **양옆 무지개가 모두** 한 화면에 들어와야 합니다.

## 파일 구조

```
index.html          허브 — 과목 선택, 사이드바, 활동 실행
style.css           공통 디자인
script.js           허브 동작과 활동 목록
worksheet.js        활동지 인쇄 · PDF · HTML 저장 (모든 활동이 공유)
*.html              활동 하나에 파일 하나 (각자 독립 실행 가능)
images/             화석 사진, 지구 자전 GIF
```

활동 파일은 저마다 독립적이라 **혼자 열어도 동작합니다.** 허브 없이 파일 하나만 학생에게 줘도 됩니다.

## 저작 · 이용

수업 목적의 자유로운 사용을 환영합니다. 화석 사진의 출처는 각 활동 안에 표기되어 있습니다.
